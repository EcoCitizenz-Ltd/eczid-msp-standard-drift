# Security

- The wrapper delegates to a full immutable commit SHA of the shared ECZ-ID MSP engine.
- No repository write permission is required by the wrapper.
- No repository code is executed by the wrapper.
- Missing ECZ-ID identity is neutral and never means unsafe, untrusted or non-compliant.
- Results are bounded evidence observations, not a universal safety, certification or compliance verdict.
- Local MSP/customer policy decides.

Report suspected vulnerabilities privately through EcoCitizenz support/security channels; never place secrets or customer-private evidence in a public issue.
